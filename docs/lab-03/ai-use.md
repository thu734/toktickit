## Reflection

I became more aware that if I simply ask the LLM to “do it perfectly,” it may add things that are outside the required scope. Because of this, I now list the specific Markdown files and lab sheet that the it should review before working on each issue. For areas where there is still room for design decisions, I ask the LLM to suggest options or ask me first instead of deciding automatically. From this experience, I learned that it is better to clearly list what I want for each issue rather than only saying “implement Issue # according to the Markdown files and lab sheet.”
